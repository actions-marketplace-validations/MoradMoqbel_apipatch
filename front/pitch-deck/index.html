03 / The Solution

End-to-end refactoring with AST verification.

ApiPatch bridges the gap between version detection and code refactoring by autonomously generating syntactic and semantic fixes.

[PASS] Python AST parsed with zero syntax errors.
[5/5] Creating fork and atomic commit...

[DONE] Pull Request opened: #261 (100% pre-merge checks passed)
1. Grounded Documentation Retrieval
Queries official package registries and changelogs before generating code, preventing LLM hallucinations about API signatures.
2. Syntax Tree Self-Healing Loop
Every refactored block must pass abstract syntax tree (AST) validation. If a syntax error is introduced, the engine corrects it automatically.
3. Non-Destructive Subproject Scope
Only modifies targeted subdirectories and related manifests, keeping surrounding files completely untouched.
04 / Architecture

A deterministic migration pipeline.

Designed to ensure that every pull request submitted is safe, syntactically sound, and directly reviewable by maintainers.

STEP 01
Repository Ingestion
Parses package manifests (requirements.txt, package.json) and scans source files in parallel.
STEP 02
Doc Retrieval
Pulls exact migration notes and changelogs from verified package registries and repositories.
STEP 03
Refactor Engine
LLM transforms deprecated invocations into modern client calls following official migration specs.
STEP 04
AST Validation
Validates the code structure using language parsers (ast module in Python, Babel in JS/TS).
STEP 05
Atomic PR
Creates a clean branch, commits changes atomically via GitHub API, and provides a structured report.
Key Architectural Principle: ApiPatch treats LLM outputs as untrusted candidates. Code is only committed after passing static grammar validation and AST equivalence checks.
